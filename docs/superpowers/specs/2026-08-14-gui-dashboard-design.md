# 图形化主界面（浅色卡片仪表盘）设计

日期：2026-08-14
状态：已批准（布局 B 卡片式 + 浅色 + WinForms 自绘方案）

## 目标

在现有托盘基础上提供常驻「概览」主窗口：浅色圆角卡片仪表盘，一屏展示代理/直连白名单/节点/日志/守护状态，卡片点击进入对应管理页。保留托盘常驻与右键菜单，托盘双击/菜单可打开主窗口。

## 视觉与布局

- 浅色主题：窗体白底（`#F5F7FA`），卡片白底（`#FFFFFF`）淡灰描边（`#E3E7EF`），圆角 10px，悬停淡蓝高亮。
- 顶部状态条：代理徽章（在线绿 `#2A6B48/#CFE8D8`、离线红、未知灰）+ 端口 + 节点 + 模式 + 「刷新」按钮。
- 中部 2×2 卡片：
  1. **直连白名单**：家数 + 最新一条；点击打开白名单管理页。
  2. **节点**：当前节点；点击打开节点切换页。
  3. **日志**：最近日志文件大小/条数；点击打开日志查看页。
  4. **守护**：任务状态 + 「启动/停止」「开机自启」开关；点击无独立页（卡片内操作）。
- 底部操作区：添加直连 API、只读检测、重启 Codex、编辑配置。
- 窗口尺寸约 720×520，FixedDialog 可关闭；关闭窗口不退出程序（回托盘），托盘菜单「退出」才退出。

## 架构

- 新建 `src/GuardianMainForm.cs`：主窗体（自绘卡片用 Panel 子类 `RoundedCard`，OnPaint 圆角/悬停）。
- `GuardianTray.cs`：菜单加「打开主界面」，双击图标打开；保留现有全部托盘功能。
- 数据与操作全部复用现有通道：
  - 状态：`RunHelper("State")`（每 15s 周期刷新 + 手动刷新）。
  - 白名单：读 `config\daemon.config.json` 的 `directDomains` 展示；添加复用 `AddDirectForm`；删除新增 helper 动作 `RemoveDirect`（`-Value` 逗号分隔规则名），由 helper 调 `add-direct.ps1` 同款 JSON 写回逻辑的独立脚本/函数（PS 端新增 `remove-direct.ps1` 或 helper 内直接实现，二选一：**helper 内直接实现**，减少文件数）。
  - 节点：复用 `Nodes` / `SwitchNode` 动作。
  - 日志：C# 直接读 `logs\daemon.log` 尾部（无 PowerShell 开销）。
  - 守护启停/自启：复用 `Start/Stop/Enable/Disable` 动作。
  - 操作按钮：复用 `AddDirect`（弹表单）、`Detect`、`RestartCodex`、`EditConfig`。

## 页面规格

1. **白名单管理页**（模态）：上方输入框（复用 AddDirectForm 的表单与提交逻辑）；下方列表（13 家+自定义）；选中后「删除」按钮（helper RemoveDirect，写回 config，守护热重载）；删除二次确认。
2. **节点切换页**（模态）：左侧选择器组列表，右侧节点列表；点击节点即切换（SwitchNode），成功后气泡/行内提示，当前节点加粗高亮。
3. **日志查看页**（模态）：只读多行文本，显示 daemon.log 尾部约 200 行 + 底部「刷新」；不自动跟随滚动。
4. **守护卡**：任务运行中/停止时显示按钮与自启状态；操作后刷新整窗。

## 技术约束

- .NET Framework 4.8，csc 命令行编译，C# 5（无 local function / 表达式体）。
- 无第三方依赖；图形全部 GDI+ 自绘。
- build-tray.ps1 编译源文件列表追加 `src/GuardianMainForm.cs`。
- 文件编码 UTF8 BOM + CRLF；中文界面文案。
